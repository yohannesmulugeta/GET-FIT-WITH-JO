# Get Fit with JO — 2026 editorial redesign

Professional, mobile-first, static website for Joseph Abraham / Get Fit with JO.

## Run locally

Serve this directory with a local static server, e.g. `python -m http.server 8000`, then open `http://localhost:8000`. Double-clicking `index.html` works for most content, but local server testing is recommended for media.

## Deployment

Push the files to `main`; the repository GitHub Pages workflow publishes from the repository root. Site URL: https://yohannesmulugeta.github.io/GET-FIT-WITH-JO/

## Creative and factual integrity

- The images `joseph-*concept.webp` and `joseph-avatar.webp` are **AI-generated visual concepts based on photos supplied for the site**. They are not original documentary photographs. Joseph should approve resemblance and use before launch. They must not be presented as evidence of actual client sessions, qualifications, achievements or facilities.
- The `original-*.jpg` and `original-*.mp4` assets remain unaltered in the repository. The gallery shows three real supplied clips, with posters generated from those original videos.
- The public page removes unconfirmed social-profile links, client-count/certification figures, an unfinished partnership reference, a named third-party medical history, and previously shown unconfirmed package prices.
- The provided phone number, WhatsApp number and email are retained pending confirmation with Joseph.
- Programs for medical conditions are not clinical treatment; the site includes an appropriate disclaimer.
- Brand tokens preserved: dark navy `#0A1526`, navy `#12213B`, orange `#FF6A3D`, teal `#17A398`, off-white `#F5F6F2`.
- No analytics/tracking was added. The site works without cookies, a database, or third-party build dependencies.

## Files

- `index.html`: semantic content and basic SEO metadata
- `styles.css`: responsive design system and page styles
- `script.js`: accessible mobile menu, video playback behaviour
- `assets/`: generated design concepts, original photo/video archive, video poster images, favicon
- `robots.txt`, `sitemap.xml`: basic discovery metadata
